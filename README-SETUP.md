# הגדרת בוט רשימת הקניות — מדריך שלב אחר שלב

## שלב 1: צור בוט טלגרם (2 דקות)

1. פתח טלגרם וחפש **@BotFather**
2. שלח לו: `/newbot`
3. הוא ישאל לשם — כתוב לדוגמה: `Shopping List`
4. הוא ישאל לשם משתמש — כתוב לדוגמה: `amit_yarden_shop_bot`
5. תקבל **טוקן** שנראה כך: `1234567890:ABCDefGH...` — שמור אותו!

## שלב 2: קבל את ה-Telegram ID שלך ושל ירדן

1. חפש בטלגרם **@userinfobot**
2. שלח לו כל הודעה (לדוגמה "היי")
3. הוא יחזיר את ה-ID המספרי שלך — שמור אותו
4. בקשי מירדן לעשות אותו דבר ושמרי את ה-ID שלה

## שלב 3: העלה את הקוד ל-GitHub

1. פתח [github.com](https://github.com) וצור חשבון אם אין לך
2. לחץ **➕** למעלה → **New repository**
3. קרא לו `shopping-bot` → לחץ **Create repository**
4. עקוב אחרי ההוראות שמופיעות בדף להעלאת הקוד

## שלב 4: פרוס ב-Railway (חינמי)

1. פתח [railway.app](https://railway.app) והתחבר עם חשבון GitHub
2. לחץ **New Project** → **Deploy from GitHub repo**
3. בחר את `shopping-bot`
4. לחץ על הפרויקט → לשונית **Variables** → הוסף את המשתנים הבאים:

| שם משתנה | ערך |
|----------|-----|
| `BOT_TOKEN` | הטוקן שקיבלת מ-BotFather |
| `AMIT_ID` | ה-ID המספרי שלך |
| `PARTNER_ID` | ה-ID של ירדן |
| `AMIT_NAME` | עמית |
| `PARTNER_NAME` | ירדן |

5. Railway יפעיל את הבוט אוטומטית ✅

## שימוש

- שלח `/start` לבוט בטלגרם — עמית וירדן יכולים לעשות זאת מכל טלפון
- כל הפעולות נעשות דרך לחצנים — אין צורך לזכור פקודות
- כשאחד מוסיף פריט, השני מקבל הודעה אוטומטית
